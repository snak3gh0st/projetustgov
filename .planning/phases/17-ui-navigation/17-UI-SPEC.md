| Token | Value | Usage |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF / #F8FAFC | Page background (body: #F8FAFC), card interiors, slide-over panel, table row bg |
| Secondary (30%) | #F1F5F9 / gray-50 | Table row hover bg, info card bg inside slide-over, KPI card outer bg, filter select bg |
| Accent (10%) | #0072F7 | Reserved for: active nav border + text, primary CTA button bg, financial highlight values, progress bar fill, contact badge border |
| Alert | #F59E0B / amber-500 | Reserved for: alert row left border (4px solid), alert badge bg (amber-50 + amber-700 text) |
| Destructive | #EF4444 / red-500 | Not applicable in this phase (read-only view, no delete actions) |

Accent reserved for: active sidebar nav item (border-r-2 + text), the "Ver Detalhes" / primary action button, progress bar fill on % execucao bar, financial currency values in slide-over highlight rows, contact indicator badge border.

Alert color note: `tem_alerta = true` rows render with a `border-l-4 border-amber-400` left border on the table row and an inline amber badge labeled "Alerta". This is the ONLY use of amber in this phase. Distinct from the blue accent — never use blue for alert rows.

Border: `border border-gray-200` on all cards and the slide-over panel left edge. Sidebar already uses `border-r border-gray-200`.

Source: `globals.css` (body #F8FAFC), `tailwind.config.ts` (sigma.neon #0072F7, sigma.magenta #FD225C), `LeadSlideOver.tsx` (color patterns), `KPICard.tsx`

## Visual Anchor

Primary focal point on the /execucao main page: the main table — the eye is drawn first to alert rows (amber left border `border-l-4 border-amber-400`) and then to the blue financial values in the Desembolsado column (`text-[#0072F7] font-bold`). All other elements (KPI row, filter bar) support the table rather than compete with it.

## Interaction Contract

### /execucao Page
- Server component validates session; redirects vendedor to `/sem-permissao` (not login)
- Client component fetches `/api/execucao` on mount
- Search input: 300ms debounce before re-fetch (pattern from leads/page.tsx)
- UF dropdown filter: re-fetches immediately on change
- Alert toggle: checkbox or toggle labeled "Apenas alertas" — sets `alert_only=true` param
- Table row click: opens ExecucaoSlideOver for that CNPJ
- Table row with `tem_alerta=true`: `border-l-4 border-amber-400 bg-amber-50/30` class
- Loading state: skeleton shimmer OR simple "Carregando..." text in table area (consistent with existing pages using `loading` boolean)
- Freshness timestamp: rendered below page title as `text-xs text-gray-400` — text: "Dados atualizados em {data}"

### Sidebar Modification
- Add nav entry `{ href: '/execucao', label: 'Projetos em Execucao', icon: 'execucao' }` to gestor and coordenador nav arrays only
- Add a new `case 'execucao'` to `NavIcon` switch: use Heroicons `ChartBarIcon` SVG (bar chart variant, strokeWidth 1.5)
- Vendedor nav array: no change — /execucao not added

### ExecucaoSlideOver
- Opens on row click, closes on backdrop click or Escape key
- Fetches `/api/execucao/{cnpj}` on open (lazy — not pre-fetched)
- Loading state inside slide-over: `text-sm text-gray-400` centered "Carregando convenios..."
- Per-convenio progress bar: `<div class="bg-gray-100 rounded-full h-2"><div class="bg-[#0072F7] h-2 rounded-full" style="width: {pct}%"/></div>`
- Progress bar capped at 100% (pct_execucao may exceed 100 in edge cases)
- `dias_ate_vencimento` < 30: render value in `text-red-500 font-medium` (urgency signal)
- `dias_ate_vencimento` 30–90: render in `text-amber-600`
- `dias_ate_vencimento` > 90: render in `text-gray-600`

## Table Columns (UI-04)

Main table on /execucao page — columns in order:

| # | Column Header | Data Field | Formatting |
|---|--------------|------------|------------|
| 1 | CNPJ | cnpj | `formatCNPJ()` mono font |
| 2 | Nome | nome_proponente | truncate with title attribute |
| 3 | UF | uf | uppercase, text-gray-500 |
| 4 | Fomentos | total_projetos | large font-bold text-gray-900 (big number) |
| 5 | Desembolsado | total_desembolsado | `formatCompactCurrency()` text-[#0072F7] |
| 6 | Saldo em Conta | total_saldo | `formatCompactCurrency()` text-gray-700 |
| 7 | % Execucao | pct_execucao_ponderado | "{N}%" text-gray-700, "--" if null |
| 8 | Vigencia | data_fim_vigencia_mais_proxima | "DD/MM/AAAA" text-gray-500 |
| 9 | Alerta | tem_alerta | amber badge "Alerta" if true, empty if false |
| 10 | Contato | contact_present | blue dot badge if true, empty if false |

Table header: `text-xs font-medium text-gray-500 uppercase tracking-wider bg-gray-50 border-b border-gray-200`
Table row: `hover:bg-gray-50 cursor-pointer border-b border-gray-100 transition-colors`
Alert row override: `border-l-4 border-amber-400 bg-amber-50/30`

## Accessibility Notes

- Slide-over: `role="dialog"` `aria-modal="true"` `aria-label="Detalhes do proponente"`
- Table rows: `role="row"` with `tabIndex={0}` and `onKeyDown` Enter/Space to open slide-over
- Alert badge: `aria-label="Projeto com alerta de desembolso zero"`
- Progress bar: `role="progressbar"` `aria-valuenow={pct}` `aria-valuemin={0}` `aria-valuemax={100}`
- All color-only signals (alert amber, contact blue) have accompanying text label or icon for screen readers
