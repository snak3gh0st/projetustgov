<task type="auto">
  <name>Task 1: Component wrapper modules (cards, kpi, badges)</name>
  <files>src/dashboard/components/cards.py, src/dashboard/components/kpi.py, src/dashboard/components/badges.py</files>
  <action>
1. Create `src/dashboard/components/cards.py`:
   - `glassmorphic_card(content: str, card_class: str = "glassmorphic-card") -> None`: Wraps content in a div with the glassmorphic-card CSS class, renders via st.html(). Content parameter is raw HTML string.
   - `glassmorphic_container(title: str | None = None) -> None`: Higher-level wrapper that adds an optional title (h3, styled with --font-heading) inside the glassmorphic card. For wrapping sections of the page.

2. Create `src/dashboard/components/kpi.py`:
   - `premium_kpi_card(label: str, value: str | int | float, delta: str | None = None, delta_color: str = "gray", icon: str | None = None) -> None`:
     - Formats value: if int, use f"{value:,}" (comma separator). If float, use f"{value:,.2f}". If str, pass through.
     - Builds HTML with classes: premium-kpi-card container, kpi-label, kpi-value, kpi-delta (with delta-{color} variant).
     - If icon provided, prepend to label as small emoji/text.
     - Renders via st.html().
   - `kpi_row(cards: list[dict]) -> None`: Convenience function that takes a list of dicts (each with label, value, delta, delta_color keys) and renders them in a horizontal flex row using a single st.html() call. This avoids multiple st.html() calls which create separate containers. The row HTML: `<div style="display: grid; grid-template-columns: repeat({n}, 1fr); gap: 1rem;">` wrapping multiple premium-kpi-card divs.

3. Create `src/dashboard/components/badges.py`:
   - `value_badge(text: str, variant: str = "gray") -> str`: Returns HTML string for a pill badge. Variant: "green", "blue", "amber", "gray". Returns string (not renders) so it can be embedded in other HTML.
   - `status_indicator(label: str, variant: str = "gray") -> str`: Returns HTML string for a small colored dot + label text. For inline status display.
   - `freshness_badge(status: str) -> str`: Convenience that maps freshness status ("fresh" -> green/"Atualizado", "stale" -> amber/"Desatualizado", "critical" -> red/"Critico") to a value_badge call. Returns HTML string.

All functions must use the exact CSS class names defined in Plan 01's components.css (glassmorphic-card, premium-kpi-card, kpi-label, kpi-value, kpi-delta, delta-green, delta-red, delta-gray, value-badge, value-badge--green, etc.).
