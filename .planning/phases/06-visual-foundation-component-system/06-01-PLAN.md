  <files>src/dashboard/streamlit_app.py</files>
  <action>
Add a `load_css()` function to `src/dashboard/streamlit_app.py` that:

1. Define load_css() function AFTER st.set_page_config() call (line 23):
   - Uses Path(__file__).parent / "assets" / "styles" to locate CSS directory
   - Reads each CSS file in order: fonts.css, theme.css, components.css
   - For each file, reads the text content and injects via st.html() wrapped in a style tag: `st.html(f"<style>{css_content}</style>")`
   - NOTE: Do NOT pass file paths directly to st.html() — read the file content first, then wrap in style tags. Research noted st.html() with file paths may have caching issues in Streamlit 1.42+.

2. Call load_css() immediately after set_page_config() and BEFORE session state initialization (before line 26).

3. Keep ALL existing functionality intact: session state init, page definitions, navigation. Do not modify any page functions or navigation structure.

IMPORTANT: The CSS loading must happen on every page load (not conditional). Streamlit re-runs the entire script on each interaction, so load_css() will naturally execute each time.
  </action>
