  <context>
The alerta_desembolso column in projetos_execucao was computed in the ETL as `valor_desembolsado < 0`. This condition never fires for real government disbursement data because valor_desembolsado is always positive (money transferred to the beneficiary).

The client must identify specific convenios that should trigger the alert so the developer can inspect them in the database and derive the real SQL condition.

The STATE.md documents this as a Phase 16 blocker: "Client must identify 3+ convenios that should show the alert and 3+ that are healthy before Phase 16 plan 2 can be executed."

**Possible interpretations (from RESEARCH.md Open Question 1):**
- Low pct_execucao combined with expiring data_fim_vigencia
- saldo_conta <= 0 with dias_ate_vencimento < 90
- Something entirely different the client defines

**To help the client decide, run these diagnostic queries on Supabase:**

```sql
-- Distribution of pct_execucao to understand what "typical" looks like
SELECT
  CASE
    WHEN pct_execucao IS NULL THEN 'NULL'
    WHEN pct_execucao < 10 THEN '0-10%'
    WHEN pct_execucao < 25 THEN '10-25%'
    WHEN pct_execucao < 50 THEN '25-50%'
    WHEN pct_execucao < 75 THEN '50-75%'
    ELSE '75-100%+'
  END AS bucket,
  COUNT(*) AS count
FROM projetos_execucao
GROUP BY 1
ORDER BY 1;

-- Projects with verificar_saldo = true (desembolsado > 0 but saldo_conta <= 0)
SELECT COUNT(*) FROM projetos_execucao WHERE verificar_saldo = TRUE;

-- Projects expiring within 90 days
SELECT COUNT(*) FROM projetos_execucao
WHERE data_fim_vigencia IS NOT NULL
  AND data_fim_vigencia < NOW() + INTERVAL '90 days';

-- Sample "potentially problematic" projects for client review
SELECT
  nr_convenio, cnpj, nome_proponente,
  valor_repasse, valor_desembolsado, saldo_conta,
  pct_execucao, dias_em_execucao, dias_ate_vencimento,
  data_fim_vigencia
FROM projetos_execucao
WHERE verificar_saldo = TRUE
  OR (pct_execucao < 10 AND dias_em_execucao > 365)
ORDER BY pct_execucao ASC NULLS FIRST
LIMIT 20;
```

Share these results with the client and ask them to identify:
1. 3+ convenios from the results that SHOULD show the alert
2. 3+ convenios that they consider healthy (no alert needed)
