<task type="auto">
  <name>Task 2: Create chart data aggregation queries</name>
  <files>src/dashboard/queries/chart_data.py</files>
  <action>
  Create `src/dashboard/queries/chart_data.py` with 4 cached query functions. Follow existing patterns from `qualificacao.py` and `metrics.py` (use get_db_engine(), @st.cache_data, raw SQL via text()).

  a) `get_proponentes_por_estado() -> pd.DataFrame`
     - Query: SELECT estado, COUNT(*) as total_proponentes, SUM(total_emendas) as total_emendas, SUM(valor_total_emendas) as total_valor_emendas FROM proponentes WHERE natureza_juridica NOT ILIKE '%Administra%' AND estado IS NOT NULL GROUP BY estado ORDER BY total_proponentes DESC
     - Cache TTL: 30m
     - Returns DataFrame with columns: estado, total_proponentes, total_emendas, total_valor_emendas
     - This feeds the choropleth map (color by total_proponentes -- most useful for sales reps to see geographic concentration)

  b) `get_value_distribution() -> pd.DataFrame`
     - Query: Categorize proponentes into value tiers based on total_propostas:
       - '1 proposta (Alto Valor)' for total_propostas = 1
       - '2-3 propostas (Bom Valor)' for total_propostas BETWEEN 2 AND 3
       - '4-5 propostas (Medio)' for total_propostas BETWEEN 4 AND 5
       - '6-10 propostas (Baixo)' for total_propostas BETWEEN 6 AND 10
       - '10+ propostas (Muito Baixo)' for total_propostas > 10
     - Use CASE WHEN in SQL to create tiers
     - Filter: natureza_juridica NOT ILIKE '%Administra%'
     - Cache TTL: 30m
     - Returns DataFrame with columns: faixa, quantidade
     - Order by value tier (Alto Valor first)

  c) `get_propostas_trend(granularity: str = 'monthly') -> pd.DataFrame`
     - Query propostas with data_publicacao grouped by period
     - Monthly: DATE_TRUNC('month', data_publicacao) as periodo
     - Yearly: EXTRACT(YEAR FROM data_publicacao) as periodo
     - Count propostas per period and sum valor_global
     - Filter: data_publicacao IS NOT NULL
     - Cache TTL: 30m
     - Returns DataFrame with columns: periodo, total_propostas, valor_total
     - Order by periodo ASC

  d) `get_extraction_sparkline_data(days: int = 30) -> dict[str, list[float]]`
     - Query extraction_logs for last N days
     - Return dict with keys matching entity names: {'propostas': [count_day1, count_day2, ...], 'total_records': [...]}
     - Extract total_records per day from extraction_logs table
     - If fewer than 3 data points, return empty dict (sparklines need minimum data)
     - Cache TTL: 10m (same as metrics queries)
  </action>
