  <action>
Create `src/dashboard/assets/styles/responsive.css` with:

1. **KPI grid responsive breakpoints:**
   - Mobile (max-width: 599px): `.kpi-row { grid-template-columns: 1fr; }`
   - Tablet (600px-767px): `.kpi-row { grid-template-columns: repeat(2, 1fr); }`
   - Desktop (768px+): `.kpi-row { grid-template-columns: repeat(4, 1fr); }` (keep existing behavior)

2. **Table horizontal scroll on mobile:**
   - `@media (max-width: 767px)` target `[data-testid="stDataFrame"]` with `overflow-x: auto; -webkit-overflow-scrolling: touch;`

3. **Search bar mobile optimization:**
   - Ensure sidebar search input is full-width on mobile
   - `[data-testid="stSidebar"] input { width: 100%; }`

4. **Touch device hover protection:**
   - `@media (hover: none) { .glassmorphic-card:hover, .premium-kpi-card:hover { transform: none; box-shadow: inherit; } }`

5. **Reduced motion accessibility:**
   - `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }`

6. **Mobile backdrop-filter reduction:**
   - `@media (max-width: 767px) { .glassmorphic-card, .premium-kpi-card { backdrop-filter: blur(8px); -webkit-backdrop-filter: blur(8px); } }`

Update `src/dashboard/assets/styles/components.css` with:

7. **Card hover effects** (add to existing `.glassmorphic-card` and `.premium-kpi-card` rules):
   - `transition: transform 0.3s ease, box-shadow 0.3s ease;`
   - `:hover { transform: translateY(-2px); box-shadow: 0 0 20px rgba(0, 212, 255, 0.3); }`

8. **Fade-in animation:**
   - Add `@keyframes fadeIn` (from opacity:0, translateY:10px to opacity:1, translateY:0)
   - Add `.fade-in-content { animation: fadeIn 0.4s ease-out; }`
   - Apply `.fade-in-content` class to `.glassmorphic-card`

9. **Status pill badges:**
   - `.pill-badge { display: inline-flex; align-items: center; padding: 4px 12px; border-radius: 999px; font-size: 0.75rem; font-weight: 600; font-family: 'Inter', sans-serif; letter-spacing: 0.02em; }`
   - Variants: `.pill-badge--green { background: rgba(0, 200, 83, 0.15); color: #00C853; border: 1px solid rgba(0, 200, 83, 0.3); }`
   - `.pill-badge--blue { background: rgba(0, 212, 255, 0.15); color: #00D4FF; border: 1px solid rgba(0, 212, 255, 0.3); }`
   - `.pill-badge--amber { background: rgba(255, 171, 0, 0.15); color: #FFAB00; border: 1px solid rgba(255, 171, 0, 0.3); }`
   - `.pill-badge--red { background: rgba(255, 61, 0, 0.15); color: #FF3D00; border: 1px solid rgba(255, 61, 0, 0.3); }`
   - `.pill-badge--gray { background: rgba(255, 255, 255, 0.08); color: #9E9E9E; border: 1px solid rgba(255, 255, 255, 0.15); }`

Do NOT use `will-change` in static CSS — let the browser optimize. Use transform/opacity only for animations (compositor-only, 60fps safe).
