**Create `src/dashboard/components/search.py`:**

`render_global_search()` function:
- Use `st.columns([4, 1])` for compact search bar layout.
- col1: `st.text_input("Buscar", placeholder="CNPJ ou Nome do Proponente...", key="global_search_input", label_visibility="collapsed")`
- col2: `st.button("Buscar", key="global_search_btn", type="primary")`
- On button click with non-empty search_term:
  - Call `search_entities(search_term, limit=10)` from `src.dashboard.queries.search`.
  - If results not empty:
    - Filter to show only proponente results first (entity_type == "proponente").
    - Display results as buttons: `st.button(f"{entity_icon} {row['nome']} ({row['cnpj']})", key=f"search_result_{idx}")`.
    - Entity icons: proponente="Proponente", proposta="Proposta", programa="Programa".
    - On result button click: set `st.session_state.selected_lead_cnpj = row["cnpj"]`, `st.session_state.selected_lead_name = row["nome"]`, then `st.switch_page("pages/lead_profile.py")`.
  - If no results: `st.warning("Nenhum resultado encontrado.")`.
- IMPORTANT: Use `st.popover("Resultados")` or `st.expander("Resultados")` to contain results without pushing page content down. Research says button-based search (not autocomplete) fits Streamlit's rerun model.
- Do NOT add glassmorphic styling to search results — use minimal dark containers per research guidance (preserve backdrop-filter budget).

**Create `src/dashboard/components/breadcrumb.py`:**

`render_breadcrumb()` function:
- Check `st.session_state.get("selected_lead_name")`.
- If lead is selected: render `st.caption(f"Home > Qualificacao > {st.session_state.selected_lead_name}")` with styled HTML via `st.html()`.
- Use `get_iframe_styles()` from `_styles.py` for consistent dark theme.
- Breadcrumb HTML: simple inline div with neon accent color for the active segment, secondary text color for prior segments. Keep it minimal — single line, small font.
- If no lead selected: render nothing (empty return).
