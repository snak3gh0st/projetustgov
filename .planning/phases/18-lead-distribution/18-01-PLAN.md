Rewrite `web/src/lib/distribute-execucao.ts` to replace the current `query()`-based implementation with a dedicated-connection approach using `getPool().connect()`. The full changes:

1. **Update imports:** Replace `import { query } from './db'` with `import { getPool } from './db'`.

2. **Update DistributeResult interface:** Add two new fields:
   ```typescript
   export interface DistributeResult {
     distributed: number
     updated: number
     inserted: number
     skipped?: boolean
     vendedores: { nome: string; before: number; assigned: number; after: number }[]
     coordenador?: { nome: string; assigned: number }
   }
   ```

3. **Add lock key constant:** `const DISTRIBUTE_LOCK_KEY = 19876543210` (documented as Phase 18 distribution lock).

4. **Wrap entire function in dedicated connection + advisory lock:**
   - Acquire client via `const client = await getPool().connect()`
   - Try `pg_try_advisory_lock(DISTRIBUTE_LOCK_KEY)` — if not acquired, return `{ distributed: 0, updated: 0, inserted: 0, vendedores: [], skipped: true }`
   - Inner try/finally releases lock via `pg_advisory_unlock(DISTRIBUTE_LOCK_KEY)`
   - Outer finally calls `client.release()`

5. **Convert all existing `query()` calls to `client.query()` calls:**
   - `query<T>(sql, params)` becomes `const { rows } = await client.query<T>(sql, params)` — note that `client.query` returns `QueryResult` not just rows, so destructure `.rows`.

6. **Add client-routing pre-step between the unassigned fetch (step 2) and the round-robin loop (step 3):**

   a. Fetch coordenador:
   ```sql
   SELECT id, nome FROM users WHERE role = 'coordenador' AND active = true ORDER BY nome ASC LIMIT 1
   ```
   Store as `coordenador` variable. If null, log warning `[distribute-execucao] No active coordenador found, client leads will enter round-robin` and skip client routing.

   b. Check which unassigned CNPJs are existing clients:
   ```sql
   SELECT REGEXP_REPLACE(ec.cnpj, '[^0-9]', '', 'g') AS cnpj
   FROM existing_clients ec
   WHERE REGEXP_REPLACE(ec.cnpj, '[^0-9]', '', 'g') = ANY($1::text[])
   ```
   Pass `unassigned.map(r => r.cnpj)` as the parameter.

   c. Split unassigned into `clientLeads` and `roundRobinLeads`:
   ```typescript
   const clientCnpjs = new Set(clientRows.map(r => r.cnpj))
   const clientLeads = unassigned.filter(r => clientCnpjs.has(r.cnpj))
   const roundRobinLeads = unassigned.filter(r => !clientCnpjs.has(r.cnpj))
   ```

   d. Assign `clientLeads` to coordenador using the same update/insert logic already in step 4 (check existing vendedor_projetos row, update or insert). Track count in `clientAssigned` variable.

7. **Modify the round-robin loop (step 3) to iterate `roundRobinLeads` instead of `unassigned`.**

8. **Update the return value:**
   - `distributed` = `assignments.length + clientAssigned`
   - Add `coordenador: coordenador ? { nome: coordenador.nome, assigned: clientAssigned } : undefined`
   - `vendedores` summary stays the same (only covers vendedores, not coordenador)

9. **Add logging:**
   - Before lock: `console.log('[distribute-execucao] Attempting advisory lock...')`
   - Lock acquired: `console.log('[distribute-execucao] Lock acquired, starting distribution')`
   - Lock not acquired: `console.log('[distribute-execucao] Lock already held, skipping')`
   - Client routing: `console.log(\`[distribute-execucao] Routed ${clientAssigned} client CNPJs to coordenador ${coordenador.nome}\`)`
   - After round-robin: `console.log(\`[distribute-execucao] Round-robin assigned ${assignments.length} CNPJs to ${vendedores.length} vendedores\`)`

export async function POST() {

    if (!session || session.role !== 'gestor') {

}
