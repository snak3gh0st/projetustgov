Fire THREE queries in parallel via `Promise.all`. Each MUST use NOT MATERIALIZED CTEs that union CRM + TGov-only sources (same union pattern as Task 1 — copy the exec_rows / apr_rows CTE shape).

Query A — totals (BI-01, BI-03, BI-04):
```sql
WITH exec_rows AS NOT MATERIALIZED (
  SELECT pe.saldo_conta, pe.valor_desembolsado, pe.valor_repasse, pe.rendimento_aplicacao, pe.situacao
  FROM projetos_execucao pe WHERE pe.nr_proposta = ANY($1::text[])
  UNION ALL
  SELECT pe.saldo_conta, pe.valor_desembolsado, pe.valor_repasse, pe.rendimento_aplicacao, pe.situacao
  FROM tgov_projetos_execucao pe WHERE pe.nr_proposta = ANY($1::text[])
    AND NOT EXISTS (SELECT 1 FROM projetos_execucao crm WHERE crm.nr_convenio = pe.nr_convenio)
),
apr_rows AS NOT MATERIALIZED (
  SELECT p.valor_global FROM propostas p WHERE p.nr_proposta = ANY($2::text[])
  UNION ALL
  SELECT tp.valor_global FROM tgov_propostas tp WHERE tp.nr_proposta = ANY($2::text[])
    AND NOT EXISTS (SELECT 1 FROM propostas crm WHERE crm.nr_proposta = tp.nr_proposta)
)
SELECT
  COALESCE(SUM(e.saldo_conta), 0) AS total_saldo_conta,
  COALESCE(SUM(e.rendimento_aplicacao), 0) AS total_rendimento,
  COALESCE(SUM(GREATEST(COALESCE(e.valor_repasse,0) - COALESCE(e.valor_desembolsado,0), 0))
    FILTER (WHERE e.situacao ILIKE 'em execu%'), 0)
    + COALESCE((SELECT SUM(valor_global) FROM apr_rows), 0) AS total_a_liberar,
  (SELECT COUNT(*) FROM exec_rows) + (SELECT COUNT(*) FROM apr_rows) AS total_projetos
FROM exec_rows e
```

Query B — by_status (BI-02): GROUP BY a normalized situacao bucket across exec_rows + apr_rows. Buckets MUST be (case-sensitive output strings):
- `'Saldo em Conta'` — exec_rows where saldo_conta > 0
- `'A Desembolsar'` — exec_rows where COALESCE(valor_desembolsado, 0) = 0 AND situacao ILIKE 'em execu%'
- `'Em Execução'` — exec_rows where situacao ILIKE 'em execu%' AND NOT in above two
- `'Prestação de Contas'` — exec_rows where situacao ILIKE '%presta%conta%'
- `'Em Aprovação'` — apr_rows (all)
- `'Outros'` — anything else

Return columns `bucket TEXT, count INT, value NUMERIC`. value = sum of saldo_conta for exec buckets, sum of valor_global for aprovacao bucket.

Return the same shape as Query B but always emit all six rows (use `LEFT JOIN ... USING (bucket)` against a hard-coded VALUES list, OR run Query B and reorder client-side — pick LEFT JOIN approach to keep the response stable).
