  <files>web/src/components/NewsBanner.tsx</files>
  <action>
Create a 'use client' component `NewsBanner` in `web/src/components/NewsBanner.tsx`.

**Data structure:** Define a constant at the top of the file:
```ts
const NEWS_VERSION = 'v4.0'
const NEWS_ITEMS = [
  'Projetos em Execucao — nova pagina de inteligencia pos-venda',
  'Monitoramento de alertas para projetos sem desembolso',
  'Removida aba "Importar Planilha" do menu lateral',
  'Melhorias gerais de performance e estabilidade',
]
const STORAGE_KEY = `projetus-news-dismissed-${NEWS_VERSION}`
```

**State management:**
- Use `useState<boolean>(true)` for `dismissed` (start hidden to avoid flash)
- Use `useEffect` on mount to check `localStorage.getItem(STORAGE_KEY)` — if NOT 'true', set `dismissed` to `false` (show the banner)
- If dismissed is true, return null (render nothing)

**Dismiss handler:**
- `handleDismiss`: set `localStorage.setItem(STORAGE_KEY, 'true')`, set `dismissed` to `true`

**Visual design — a horizontal banner at the top of the content area:**
- Outer div: `bg-gradient-to-r from-[#FD225C]/5 via-[#7A4BAC]/5 to-[#0072F7]/5 border border-[#7A4BAC]/20 rounded-lg p-4 mb-6 relative`
- Header row (flex between): left side has a megaphone/sparkle emoji or icon + "Novidades — {NEWS_VERSION}" in font-semibold text-gray-800; right side has the X dismiss button
- X button: `text-gray-400 hover:text-gray-600 transition-colors` using an X SVG (heroicons style, 20x20)
- News items: `<ul>` with `list-disc list-inside text-sm text-gray-600 mt-2 space-y-1`, each item as `<li>`
- Footer text: small `text-xs text-gray-400 mt-3` saying "Projetus CRM {NEWS_VERSION} — SigmaIntel"

Do NOT use any external libraries. Use only React, useState, useEffect, and Tailwind classes.
